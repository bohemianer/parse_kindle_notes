# 📚 Kindle 笔记智能导出工具 (SmartBookExporter)

基于 Python 的桌面应用程序，旨在解决 Kindle 笔记（`My Clippings.txt`）“只有时间没有章节”的痛点。

它通过**读取 ePub 电子书原文**，自动将你散乱的 Kindle 标注（Highlights）**精准匹配到对应的书籍章节**中，并导出为格式整洁的 Markdown 文件，方便导入 Notion、Obsidian 或 Logseq 等笔记软件。

---

## ✨ 核心功能

* **📖 智能章节匹配**：不再是一股脑的线性笔记。程序会解析 ePub 的目录结构（TOC）和正文，将你的每一条笔记自动归类到它所属的 `H1` / `H2` 章节下。
* **🧹 智能去重 (Smart Deduplication)**：Kindle 常常会产生重复的标注（例如先标了一句话，后来又标了包含这句话的一整段）。本工具会自动检测并保留最完整的版本，移除冗余的子集。
* **🎨 现代化暗色 UI**：基于 Tkinter 构建的深色模式界面，针对 Windows、macOS 和 Linux 进行了字体和滚轮操作的深度适配。
* **🚀 一键导出 Markdown**：生成的文件包含层级分明的标题，可以直接作为读书笔记存档。

## 🚀 使用指南

1. **启动软件**：
运行主脚本：
```bash
python export_kindle_notes.py

```


2. **加载笔记文件 (Step 1)**：
* 软件会自动尝试读取默认路径下的 `My Clippings.txt`。
* 如果未找到，请点击 **“📂 浏览”** 按钮，手动选择连接 Kindle 后根目录下的 `My Clippings.txt` 文件。


3. **选择书籍**：
* 中间的列表会自动解析出笔记文件中包含的所有书籍名称。
* **点击** 你想要导出的那本书。


4. **加载 ePub 原文 (Step 2)**：
* 为了实现章节定位，你需要提供该书对应的 **ePub** 文件（无 DRM 保护）。
* 点击 **“🔗 解析 ePub”** 并选择文件。
* *提示：如果状态栏显示 “✅ 成功解析 X 章节”，说明解析成功。*


5. **导出笔记**：
* 点击底部的 **“🚀 导出笔记”** 按钮。
* 处理完成后，整理好的 `.md` 文件将自动保存到你的 **桌面/Matched_Notes** 文件夹中，并自动打开该文件夹。

## 🧩 技术原理 (How it works)

1. **指纹清洗**：
* 工具会将 Kindle 笔记和 ePub 章节内容中的所有标点符号、空白字符移除，生成“纯文本指纹”。


2. **定位算法**：
* 遍历 ePub 的每一章，检查该章节的文本流中是否包含笔记的指纹。
* 一旦匹配成功，该笔记就会被打上章节 ID 的标签。


3. **层级重建**：
* 利用 `ebooklib` 解析 ePub 的 NCX/TOC 目录树，获取章节的父子关系（如：第一卷 -> 第一章）。导出时会尽量还原这种层级结构。

## ⚠️ 常见问题 (FAQ)

**Q: 为什么有些笔记显示在“未归类笔记”里？**
A: 这通常是因为 Kindle 笔记的内容与 ePub 文件内容不完全一致。

* 可能版本不同（例如：笔记是针对“2018版”，ePub 是“2020修订版”）。
* ePub 可能是扫描版或排版极其混乱，导致无法提取有效文本。

**Q: 为什么解析 ePub 失败？**
A: 请确保 ePub 文件**没有 DRM 保护**（即可以正常解压和阅读的文件）。受版权保护加密的 ePub 无法读取内容。

**Q: Linux 下滚轮无法使用？**
A: 代码中已针对 Linux (`Button-4`, `Button-5`) 做了事件绑定，但部分发行版可能存在差异。
